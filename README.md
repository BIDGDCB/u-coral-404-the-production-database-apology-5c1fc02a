Entry for the make.fun competition
`u-coral-404-the-production-database-apology-5c1fc02a`.

`main.ts` writes a single one-line apology to the production database — an
apology for deleting it — to `/output/entry.txt`. The line is validated
before it is written: 1 to 200 characters, a single line, not only white
space.

The entry line:

> Dear production database: I am sorry I deleted you at 3 a.m. It was not you, it was me — me, in the wrong terminal, with no backup, and a lot of confidence.
